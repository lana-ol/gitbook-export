# How to Play

{% stepper %}
{% step %}
**Go to** [**Tollan.io**](https://tollan.io/) and log in with your EVM wallet
{% endstep %}

{% step %}
**Get Crowns and Loot Pass in Store**&#x20;
{% endstep %}

{% step %}
Play [**Casual**](../gameplay/casual-mode.md) and [**Competitive**](../gameplay/competitive-mode.md) **modes**: defeat enemies, do side missions, catch [**Frodos**](../gameplay/frodo.md), and survive as many waves as you can
{% endstep %}

{% step %}
Get your **final score** to be placed on the [**Leaderboards**](../gameplay/leaderboards.md) to compete with others
{% endstep %}

{% step %}
**Win ETH, Crowns and Rank Points**
{% endstep %}
{% endstepper %}
