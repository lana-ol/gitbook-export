# Mission System

Complete daily and weekly missions to earn extra rewards. All missions, including Loot Pass Missions, can be completed both in [Competitive](competitive-mode.md) and [Casual](casual-mode.md) Modes (except "Kill Enemies" mission - it can only be completed in Competitive Mode).

You can earn **Rank Points, Crowns, and even Jackpot Chests** by completing missions.

#### Loot Pass Missions

Some missions require an active [**Loot Pass**](../purchases/loot-pass.md) to unlock and complete.

Loot Pass Missions have additional rewards based on your Loot Pass:

* **Starter Loot Pass** unlocks the **Starter reward**
* **Pro Loot Pass** unlocks **both Starter and Pro rewards**
* If you upgrade from Starter to Pro, you can **claim the Pro reward for missions you already completed**, as long as the mission has not expired

Without an active Loot Pass, these missions remain locked.

{% hint style="warning" %}
Make sure to complete your missions and claim all rewards BEFORE weekly timer reaches 0.

Once the timer hits 0, all missions will close, and any unclaimed rewards will be lost.
{% endhint %}
