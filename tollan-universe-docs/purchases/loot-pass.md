# Loot Pass

Loot Pass unlocks **rewards in** [**Casual Mode**](../gameplay/casual-mode.md) and provides additional benefits in Competitive Mode.

<figure><img src="../.gitbook/assets/Visual_Lootpass.png" alt="" width="563"><figcaption></figcaption></figure>

### Pro Loot Pass

* **45 Casual Credits per week**&#x20;
* Earn up to **\~150,000 Rank Points per week** in Casual Mode _(2.5x faster than in Competitive Mode)_
* Access to **all Loot Pass daily and weekly Mission rewards**
* **2x Crown Jackpot chances** in Casual Mode
* **+20% Rank Points** from Competitive Mode runs
* **150,000 Rank Points weekly limit**
* Access to **Casual Peak Run Leaderboard** and Crown rewards

**Price: from \~10$ worth of ETH per week**

### Starter Loot Pass

* **20 Casual Credits per week**
* Earn up to **93,000 Rank Points per week** in Casual Mode _(1.5x faster than in Competitive Mode)_
* Access to **Starter Loot Pass daily and weekly Mission rewards**
* **Crown Jackpot** in Casual Mode
* **+10% Rank Points** from Competitive Mode runs
* Access to **Casual Peak Run Leaderboard** and Crown rewards

**Price: from \~5$ worth of ETH per week**
