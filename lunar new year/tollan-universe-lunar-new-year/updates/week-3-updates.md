# Week 3 Updates

#### **🔄 Affinity Re-roll gets BETTER and CHEAPER**

* Price: 200 Crowns for non-VIP, 100 for VIP. No price increase for additional rerolls.
* Updated Affinity re-roll system - You can never roll back into 1 affinity. (Detailed explanation available below)

Affinity Reroll results can now be 2, 3, or 4 affinities, NEVER 1.

* If you have **1 affinity** (example: Wind)
  * If the result is 2 or 3 affinities, Wind will NOT be included.
  * Wind can only appear again if you roll 4 affinities.
* If you have **2 affinities** (example: Wind + Fire)
  * If the result is **2 affinities**:
    * You get **either Wind or Fire** (only one of them), plus **Water or Energy**.
  * If the result is **3 affinities**:
    * You get **either Wind or Fire**, plus **Water and Energy**.
* If you have **3 affinities** (example: Wind + Fire + Water)
  * In **all cases**, the missing affinity (**Energy**) is **guaranteed** to appear.
  * The remaining affinities are selected randomly.

#### **⚔️ Gameplay & Progression**

* Players can now **evolve one additional skill** after all shrines have been claimed.
* Various improvements to skills, enemy spawning, and overall gameplay balance.
* New Enemy - Wolf 🐺

#### **🔑 Keys & Shrines**

* Increased the number of keys on the minimap by 10.
* Updated the required number of keys to activate shrines.
* Blood Totem has been replaced with the Knowledge Shrine.
* Key drop animation is now faster
* Shrine icons are now always visible on the minimap.
* Increased Maximum Key Count to 110

#### **🔁 Re-roll & Stability Fixes**

* Fixed a bug where players could get stuck during purchases of Affinity re-roll and Skill re-roll.
* Fixed an issue where players could get stuck after leveling up.
* Fixed a rare issue where the game could get stuck after reviving at a shrine.

#### **🎮 Practice Mode Updates**

* Bonus Enemies now drop 3–6 Crowns
* Hunter's Badge now works in Practice Mode - if you have Hunter’s badge, the spawn chance of Bonus Enemy is increased by 10% (30% total).

#### **🎨 UI & Visual Updates**

* Added a fire animation to the Affinity UI when the timer drops below 10 seconds.
* Added functionality to view inventory on the Inventory Selection screen.

#### **🌐 Other Updates**

* Updated the upvote flow: the Upvote button on tollan.io now prompts to sign the Upvote transaction instead of redirecting to Abstract portal
* Fixed an issue where Whirling Winds was not dealing damage.
* Fixed Firestorm (Windgale Mutation) behavior:
  * Firestorm now properly deals damage when enemies are within its range
  * Windgale pull and damage effects now function as intended
* Runs started shortly before the leaderboard timer expires need to be completed within 30 minutes after the timer hits 00 to be counted towards the leaderboard.
