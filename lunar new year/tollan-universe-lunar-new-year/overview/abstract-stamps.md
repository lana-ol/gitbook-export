# ✳️ Abstract Stamps

Abstract Stamps determine your share of weekly Abstract XP distribution.

{% hint style="success" %}
**MORE Abstract Stamps = MORE Abstract XP**
{% endhint %}

How to earn Abstract Stamps&#x20;

* catch [Bonus Enemies](../gameplay/bonus-enemy.md) in both Seasonal Mode and Practice Mode
* rank in the Top-200 on the [Powerboard](../gameplay/leaderboards.md) and [Peak Run](../gameplay/leaderboards.md)
* receive is from [Lunar Envelopes](../lunar-new-year/lunar-envelopes-and-skins.md) and [Reward Chests](../gameplay/chest-rewards-system.md)&#x20;

Bonus Enemy Drop Rates, Multiplier, and Weekly Caps:

#### **Drop Rate**

* **Non-VIP:** 1-250 Stamps per kill
* **VIP:** 250-600 Stamps per kill

#### Point Multiplier on Abstract Stamps

[Learn how to earn more Abstract Stamps with a Point Multiplier.](../gameplay/seasonal-mode.md)

#### **Weekly Caps**

* **Non-VIP:** up to **25,000** Stamps
* **VIP:** up to **100,000** Stamps

{% hint style="warning" %}
Note: _Abstract Stamps are NOT 1:1 to Abstract XP._&#x20;
{% endhint %}

{% hint style="info" %}
Abstract Stamps balance resets every week, together with Powerboard and Peak Run Leaderboards.
{% endhint %}
