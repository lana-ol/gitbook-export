# Practice Mode

In Practice Mode, you can learn how to play the game and earn Abstract Stamps.

* Earn 10-100 Abstract Stamps for each Practice [Bonus Enemy](bonus-enemy.md) kill
* Survive up to 10 waves of enemies
* Earn [Legendary Chest ](chest-rewards-system.md)by beating all 10 waves for the first time each week

{% hint style="success" %}
Spawn chance of Bonus Enemy in Practice Mode can be increased with [**Hunter’s Badge**](../purchases/hunters-badge.md)&#x20;
{% endhint %}
