# Jackpot

{% columns %}
{% column %}
* 10% of all Crowns spent go into Jackpot
* Jackpot Chest is a part of [Chest Rewards System](chest-rewards-system.md)&#x20;
* Chests have 30% chance to drop from [Bonus Enemies](bonus-enemy.md) (subject to change). Jackpot chest drops on the map. Walk through them to collect them.
* Rewards include ETH and Powerboard Points
* Hit the Jackpot and claim ETH instantly in Inventory
{% endcolumn %}

{% endcolumn %}
{% endcolumns %}

{% hint style="warning" %}
* You will lose earned Jackpot Chest if you quit the run
* Only one Jackpot Chest can be won per run
* You have 3 hours to open a Jackpot Chest after it dropped
{% endhint %}
