# Casual Mode

Casual Mode lets you **earn Rank Points faster than in Competitive Mode, and compete for Crowns.**

Gameplay is similar to [Competitive Mode](competitive-mode.md), but Casual Mode uses **Casual Credits** to start runs and has separate rewards and Leaderboard.

* You can play Casual Mode **without a** [**Loot Pass**](../purchases/loot-pass.md)
* An active [**Loot Pass**](../purchases/loot-pass.md) **is required to earn Casual Mode rewards**, including Rank Points, Crowns, and access to the [Casual Peak Run Leaderboard](leaderboards.md)

### Casual Credits

Casual Credits are used to start Casual Mode runs.

Before each run, select how many **Casual Credits** you want to use. The amount selected determines your **Rank Points Multiplier** and increases your chance of getting a [**Crown Jackpot**](crown-jackpot.md).

#### How to get Casual Credits

**Weekly Loot Pass Rewards**

* **Starter Loot Pass:** 14 Casual Credits per week
* **Pro Loot Pass:** 35 Casual Credits per week

Weekly Casual Credits **must be claimed from your Inventory**.

**Upvoting**

You can also earn Casual Credits by upvoting Tollan Universe:

* **Without a Loot Pass:** 3 Casual Credits&#x20;
* **Starter Loot Pass:** 6 Casual Credits
* **Pro Loot Pass:** 10 Casual Credits&#x20;

### Rank Points Multiplier

The number of Casual Credits used for a run determines your Rank Points Multiplier:

* **1x** Rank Points for 1–4 Casual Credits
* **4x** Rank Points for 5–14 Casual Credits
* **9x** Rank Points for 15–39 Casual Credits
* **15x** Rank Points for 40–79 Casual Credits
* **20x** Rank Points for 80–200 Casual Credits

{% hint style="info" %}
Rank Points can be earned in Casual Mode only with an **active Loot Pass**.
{% endhint %}

### Crown Rewards

With an active Loot Pass, you can earn Crowns in Casual Mode in two ways:

* [**Crown Jackpot**](crown-jackpot.md)**:** Catch [Frodo](frodo.md) for a chance to win a Crown Jackpot. Your Jackpot chance increases based on the number of Casual Credits selected before the run.
* [**Casual Peak Run Leaderboard**](leaderboards.md)**:** Compete with other players for Crown rewards based on your best Casual Mode runs.
