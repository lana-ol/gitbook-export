# Crown Jackpot

{% columns %}
{% column %}
* Crown Jackpot Chests have a chance to drop from [Frodo](frodo.md) in [Casual Mode](casual-mode.md). Crown Jackpot Chest drops on the map. Walk through it to collect it.
* Chances are scaling with how many **Casual Credits** you used to start the run
* Rewards include Crowns (see below)
