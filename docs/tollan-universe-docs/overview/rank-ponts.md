# Rank Ponts

Rank Points help you climb Tollan Ranks, earn rewards, and build your reputation across the Tollan ecosystem.&#x20;

You can earn Rank Points by playing [Competitive Mode](../gameplay/competitive-mode.md) or [Casual Mode](../gameplay/casual-mode.md) with an active [Loot Pass](../purchases/loot-pass.md).&#x20;

Weekly Rank Points cap is 75,000. Can be increased to 150,000 with an active Loot Pass or VIP Pass.&#x20;

Every 125,000 Rank Points unlocks a new Rank level. Rank Points carry over between weeks.
