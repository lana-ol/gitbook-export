# VIP Pass

{% columns %}
{% column width="50%" %}
**Price:** $15 worth of ETH \
**Perks in Competitive Mode:**

* **+10% Points per run**&#x20;
* **+10% Rank Points**&#x20;
* 1 Free Affinity Reroll per day
* **50%** **off** Affinity and Skill Rerolls
* [Frodo](../gameplay/frodo.md) drops more Rank Points and Powerboard Points:
  * Drops **150-1,000 Rank Points**
  * Drops **400–12,500 Powerboard Points**
{% endcolumn %}

**Competitive Mode:**\
Frodo amount per run based on whether you have a VIP Pass and/or Hunter’s Badge:&#x20;

* No VIP & no HB → up to 2 Frodo per run&#x20;
* VIP or HB → up to 4&#x20;
* VIP + HB → up to 7&#x20;

**Casual Mode:**

* Starter Loot Pass + VIP Pass → up to 4&#x20;
* Starter Loot Pass + VIP Pass + Hunter’s Badge → up to 7 Frodos per run

{% hint style="info" %}
_Note: VIP Pass have benefits both in_ [_Competitive_](../gameplay/competitive-mode.md) _and_ [_Casual_](../gameplay/casual-mode.md) _Modes._\
_&#x56;IP perks are active for **7 event days from the moment of purchase**, regardless of leaderboards reset._\
_Event Days are not equal to Calendar Days. If event is paused (for example for maintenance reasons) your time towards expiration of VIP Pass will not be counted during that period._
{% endhint %}

{% hint style="warning" %}
* If you already have an active VIP Pass or Hunter’s Badge, and you receive one more (via promotions, giveaways, or Genesis Avatar holder rewards), it will appear in the Play section as pending.
* You cannot claim it until your currently active VIP Pass/Hunter's Badge expires.
* You can only hold one extra VIP Pass or Hunter’s Badge at a time. Any additional extras received will not be counted.
{% endhint %}
