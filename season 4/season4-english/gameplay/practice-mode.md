# Practice Mode

In Practice Mode, you can learn how to play the game, earn Abstract Stamps and Crowns.

* Earn Abstract Stamps Box for each Practice [Bonus Enemy](bonus-enemy.md) kill. \
  Each Box can drop 100-600 Abstract Stamps, depending on the Box Rarity (25,000 per week limit)
* Survive up to 10 waves of enemies
* Earn [Rare Chest](chests-reward-system.md) by beating all 10 waves for the first time each week

{% hint style="success" %}
Spawn chance of Bonus Enemy can be increased with [**Hunter’s Badge**](../purchases/hunters-badge.md)&#x20;
{% endhint %}
