# Jackpot



{% columns %}
{% column %}
* 25% of all Crowns spent go into Jackpot
* Jackpot Chest is a part of [Chest Rewards System](chests-reward-system.md)&#x20;
* Chests have 75% chance to drop from [Bonus Enemies](bonus-enemy.md) (subject to change). Jackpot chest drops on the map. Walk through them to collect them.
* Rewards include ETH (see below)
* Hit the Jackpot and claim ETH instantly in Inventory
{% endcolumn %}

{% endcolumn %}
{% endcolumns %}

{% hint style="warning" %}
* You will lose earned Jackpot Chest if you quit the run
* Only one Jackpot Chest can be won per run
* You have 3 hours to open a Jackpot Chest after it dropped
{% endhint %}

#### Jackpot Rewards Drop Table&#x20;

| Reward                                               | Amount               | Drop Chance |
| ---------------------------------------------------- | -------------------- | ----------- |
| <mark style="color:purple;">Mini Jackpot</mark>      | 0.07% of the Jackpot | 70%         |
| <mark style="color:purple;">Minor Jackpot</mark>     | 0.2% of the Jackpot  | 20%         |
| <mark style="color:purple;">Major Jackpot</mark>     | 0.5% of the Jackpot  | 7%          |
| <mark style="color:purple;">Legendary Jackpot</mark> | 2% of the Jackpot    | 3%          |

#### Bonus Enemy Jackpot Chests Drop Rate based on your multiplier &#x20;

| Run multiplier | Chance to get Jackpot Chest |
| -------------- | --------------------------- |
| 1x-4x          | 1%                          |
| 5x-14x         | 1.25%                       |
| 15x-39x        | 1.5%                        |
| 40x-79x        | 1.75%                       |
| 80x-200x       | 2%                          |
