# Abstract XP

Abstract XP is an incentive & engagement system from [Abstract](http://abs.xyz/), the chain Tollan Universe is deployed on.

XP can be earned in several ways on Abstract such as using apps, trading, minting, holding, etc.

The exact XP formula isn’t publicly shared, and the weekly distribution is based on changing weightings that are updated dynamically.
